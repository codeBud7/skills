# resume

**Triggers:** continue, pick up, resume kmode, session pickup
**Capabilities:** `readFiles`, `git`, `readTranscript` (optional)
**Principles:** one-check-per-slice, prove-the-artifact
**Mutates:** no, until a follow-on route starts
**Verification:** reconstructed state listed; missing pieces named

## Stages

1. Read resume note, plan file, receipts, `git status` / `git log`.
2. Optional: `readTranscript` if the note is thin.
3. Restate: route left, gates, proof already in hand.
4. Classify the remainder with kmode precedence; do not restart finished slices.

## Fallback

No note and no plan → ask for a path or start `investigate` on the branch.

## Terminal

Evidence report of current state, then hand off to the next playbook.
