# script-the-proof

The strongest proof is a command a reviewer can re-run.

**Why:** A one-shot eyeball dies with the session. A script is the lever.

**Apply when:** Proof will be repeated, delegated, or reviewed.

**Do:** Write or reuse a harness. Run it. Keep stdout/stderr or artifacts. Point `verify` at it.

**Don't:** Describe what you "would run."

**Report:** The exact command and where its output lives.
