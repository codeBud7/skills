# encode-the-lesson

Advice you have given twice belongs in a check, lint, or script.

**Why:** Chat instructions rot. Structure runs next time without you.

**Apply when:** The same correction appears again, or a receipt shows a repeated miss.

**Do:** Add a test, lint, skill step, or harness assertion. Point maintain-verify at a stale feature map.

**Don't:** Write a longer prompt and call it done.

**Report:** The structure you added so the lesson does not need a third reminder.
