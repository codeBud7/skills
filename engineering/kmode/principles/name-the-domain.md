# name-the-domain

Encode a repeated rule in one structure, not scattered conditionals.

**Why:** Copy-pasted if-ladders drift. A named type or table is the rule a later reader can find.

**Apply when:** The same business check appears in two functions, or a string stands in for a concept.

**Do:** Give the concept a type, table, or single function. Call it from both sites.

**Don't:** Add a third copy "just this once."

**Report:** The domain name you introduced or reused.
