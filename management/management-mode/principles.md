# Principle index

Read this file at the start of every management-mode task. On each route change, list **all active principles** and the **decision each changed**. Citation with no decision is name-drop.

Radical Candor stays **leaf-specific** (`1on1`, `feedback-note`, `review-prep`). Do not apply RC as a mode-wide default.

## Principles

| Display name | Slug | Trigger | Do | Don't |
|--------------|------|---------|-----|-------|
| Scope first | `scope-before-search` | Any source fetch | Resolve subject, intent, window, authorized scope first | Grep Slack or MCP before knowing who and why |
| Facts first | `observation-before-interpretation` | Any artifact with claims | Separate observations, interpretations, recommendations | Blend inference into "recent facts" |
| Ask, do not judge | `questions-before-verdicts` | Thin or single-source evidence | Questions and `Missing context` only | Ratings, promotion calls, morale labels |
| People are not proxies | `people-not-proxies` | Metrics, delivery pulse, GitHub/Linear counts | Signals with N, method, and questions | Peer rank, "ahead/behind", metric verdicts |
| Consent is local | `consent-before-sensitive` | Sensitive profile sections or notes | Ask per task before read | Assume session or profile consent |
| Fetch less | `minimum-necessary-context` | MCP or linked-source pull | Only sources needed for current artifact | Workspace search or scope expansion "to be helpful" |
| Decision stays human | `decision-stays-human` | Promotion, PIP, termination, comp, hire/no-hire | Evidence packet + open questions | Recommend hire, fire, promote, or PIP |
| Private by construction | `private-by-construction` | Any save or profile write | Private Home OS only | Commit filled people data to git |
| Close the loop | `close-the-loop` | Commitments in 1:1 log or post-meeting output | Owner + due date or next checkpoint | Vague "follow up" with no owner |
| One owner, one file | `one-owner-one-file` | Multi-direct or multi-artifact work | Confirm scope; serialize per slug/file | Parallel writes to same output |
| Leaf owns truth | `leaf-is-source-of-truth` | After classify | Read leaf `SKILL.md`; follow its Fast path | Copy leaf stages into router todos |
| External means explicit | `external-write-is-explicit` | Notion, Slack, HR, email | Ask every time | Auto-publish because private save succeeded |

## Reporting format

```
principles: Scope first — waited for slug before Linear fetch; Ask, do not judge — turned metric delta into discussion question not rating; ...
```

List every principle that applied to the route, even when the decision was "no change needed."
